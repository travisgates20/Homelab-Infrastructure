# Homelab Architecture

A hands-on enterprise-style homelab built to develop and demonstrate practical experience with systems administration, security, networking, automation, and cloud-native infrastructure.

## Goals

- Build hands-on enterprise infrastructure experience
- Practice Windows Server and Active Directory administration
- Implement security hardening and auditing
- Develop Linux administration skills
- Learn infrastructure as code and automation
- Practice troubleshooting across networking, systems, and security

## Environment

This lab is built on three physical HP Systems (3x HP Z2 mini G4) running Proxmox VE and provides an isolated environment for deploying and managing enterprise infrastructure.

Current areas of focus include:

- Proxmox virtualization
- Windows Server administration
- Active Directory Domain Services
- Group Policy management
- Windows security hardening
- Linux administration
- Network segmentation and isolation
- Security auditing and logging
- Kubernetes
- Infrastructure as code
- Automation
